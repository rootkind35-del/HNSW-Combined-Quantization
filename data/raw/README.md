# THƯ MỤC DỮ LIỆU THÔ (DATA/RAW)

Thư mục này dùng để chứa toàn bộ dữ liệu thô nguyên bản trước khi qua pipeline làm sạch và lọc trùng.

## 1. Tải dữ liệu từ Google Drive

Do giới hạn dung lượng lưu trữ của Git, các tệp dữ liệu thô (`.jsonl`) được lưu tại:
👉 **Google Drive:** [Link Tải Dữ liệu Thô](https://drive.google.com/drive/folders/1k0UfyIL_rHxtVLbNIrQvG9JE4kcvWGb2?usp=sharing)

## 2. Danh sách tệp cần đặt vào thư mục này

* `raw_crawled_news.jsonl`: Bài báo tiếng Việt tự cào từ VnExpress, Dân Trí (chứa HTML, URL, ngày đăng).
* `raw_vietnamese_corpus_10m.jsonl`: Ngữ liệu văn bản thô.
* `RAW_DATASET_MANIFEST.json`: Bảng đặc tả chi tiết cấu trúc trường dữ liệu thô.
